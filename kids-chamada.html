Ligação ao ProPresenter
Versão 7.9+ (build 21.x) — usa a nova API HTTP oficial na porta 1025. O dispositivo deve estar na mesma rede Wi-Fi que o Mac/PC com ProPresenter.
Como activar no ProPresenter
1
Vai a ProPresenter → Preferences → Network e activa "Enable Network".
2
Aponta o IP e Porta mostrados ali (ex: 192.168.1.50 porta 1025).
3
Em Tools → Messages, cria mensagens com variáveis ${numero} e ${sala} no texto.
4
Clica "Testar e Carregar" — a app carrega as mensagens automaticamente.
Aviso HTTPS: O browser pode bloquear pedidos HTTP. Abre esta página por HTTP ou como ficheiro local.
